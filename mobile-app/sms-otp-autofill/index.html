How it works

Proposed solution

1. One code field the OS can fill

Use a single code input (not six boxes) marked as a one-time code: textContentType = .oneTimeCode on iOS, autofillHints = SMS_OTP / autoComplete="sms-otp" in React Native, and the number pad keyboard. The app never reads the user's messages.

2. iOS: Security Code AutoFill

When the text arrives, iOS shows From Messages above the keypad. One tap fills the field and the app submits automatically once it has 6 digits. Codes sent by email show From Mail (iOS 17+).

3. Android: SMS User Consent

The app starts the Google Play services SMS User Consent listener before sending the code. When the text arrives, Android asks once to share that single message. Allow fills and submits the code. The SMS Retriever API can make this zero-tap by adding the app hash to the text.

4. SMS format


    
The last line binds the code to Freedom's domain, so iOS only offers it in the Freedom app (listed in its Associated Domains) and on freedommobile.ca, which helps block phishing. For zero-tap on Android, the SMS Retriever API would end the text with the app's 11-character hash instead.
